## Files
- about.html, academy.html, digital-services.html, managed-accounts.html, contact.html, privacy.html, terms.html
- assets/site.css

## Install
1. Back up the existing repository.
2. Upload the HTML files to the repository root on the main branch and `assets/site.css` to the assets folder.
3. Add links in the existing index.html navigation and footer to the new pages.
4. Test every page at https://rganmiloya-art.github.io/MILYAS-FIRM/ (e.g. https://rganmiloya-art.github.io/MILYAS-FIRM/about.html).
5. Review all working prices, founder biography, legal terms and risk disclosures before publication.
6. Verify applicable managed-account authorization before publishing that service as an active offering.
